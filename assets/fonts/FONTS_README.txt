Fonts used by Midnight Makan
----------------------------
Kenney_Future.ttf, Kenney_Future_Narrow.ttf, Kenney_Pixel.ttf
  By Kenney (www.kenney.nl), released under CC0 1.0 (public domain).
  Copied from the resources that ship with the Python Arcade library.
  Modified: the K and X glyphs were redrawn with diagonal strokes, because in
  the original design they look almost identical to H at game sizes
  ("WOK" read as "WOH"). Family names are unchanged.

Liberation_Sans_Regular.ttf, Liberation_Sans_Bold.ttf, Liberation_Sans_Italic.ttf
  Liberation Fonts, licensed under the SIL Open Font License 1.1.
  Copied unmodified from the Python Arcade library resources.
